# Vibe Coding Student Guide

A one-page printable/shareable handout for the Technovation vibe coding activity (ages 13–15).

## What it is

`index.html` is a self-contained A4-sized guide that introduces students to vibe coding — describing what you want to build in plain English and letting AI write the code. The handout walks through:

- **What vibe coding is** — a quick plain-English definition
- **3 steps** — Think of your person → Write your prompt → Refine & share
- **Prompt anatomy** — an annotated example prompt with colour-coded sections (who, what, feel)
- **Prompt tips** — practical guidance for better results
- **Where to build** — Replit as the recommended zero-install platform

## Usage

Open `index.html` directly in a browser — no build step or server needed. Print via **File → Print** or **Ctrl/Cmd+P** (print styles included).

## Customisation

All colours, fonts, and copy live in the single `index.html` file. Key CSS variables are at the top of the `<style>` block:

```css
--ink: #0f0f0f;
--paper: #faf8f4;
--accent: #7c3aed;   /* purple */
--accent2: #f59e0b;  /* amber */
```
